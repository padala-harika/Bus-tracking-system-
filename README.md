# AI College Bus Tracking System

An AI-powered smart college bus tracking system that provides real-time bus location, route optimization, and student notifications.

### Features
- Real-time Bus Location Tracking with Google Maps
- AI-based Route Optimization and ETA Prediction
- Voice Announcements using Google Text-to-Speech
- Student and Admin Dashboard
- Pickup / Drop Notifications

### Tech Stack
- **Frontend:** React + TypeScript + Vite
- **Backend:** Node.js
- **APIs:** Google Maps JavaScript API, Google Cloud TTS API

### How to Run
```bash
npm install
npm run dev
